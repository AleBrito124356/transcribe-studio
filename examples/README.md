# examples

Drop your own audio or video files here to try transcribe-studio:

```bash
python cli.py all examples/my-episode.mp3 -o results/
```

Media files in this folder (`*.mp3`, `*.mp4`, `*.wav`, `*.m4a`, `*.mkv`, `*.mov`)
are gitignored so the repository stays text-only — put anything you like here
without it showing up in `git status`.

Need a quick test clip with no copyright worries? Record a few seconds with any
phone voice-memo app, or generate a short spoken WAV with a local TTS tool, and
run the command above.
